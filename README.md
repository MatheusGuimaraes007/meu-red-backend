# CRM RED Backend

API NestJS própria para o frontend Vue do CRM RED.

## Execução

1. Copie/ajuste `.env` e troque `JWT_SECRET`, `MASTER_ADMIN_EMAIL` e `MASTER_ADMIN_PASSWORD`.
2. `npm install`
3. `npm run start:dev`

API: `http://localhost:3000/api`

O primeiro start cria `public.crm_users` e o usuário master configurado no `.env`.
